⚡ ElectroLab — How to Use

How to use

  1. Drag an apparatus from the left toolbox.
  2. Click a terminal on one component (or wire end), then click another terminal to auto-connect a wire!
  3. You can manually drag wire endpoints to snap to terminals or other wires.
  4. Drag the ↻ handle to rotate a component.
  5. Use the Remove button or Delete key to remove components.
  6. Press START SIMULATION.

Keyboard

Delete / Backspace → Remove selected
Space → Start / pause simulation
R → Reset simulation
Q → Rotate left
E → Rotate right
Escape → Deselect
